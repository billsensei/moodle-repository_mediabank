# Media bank: Funding

The Media bank is free software, released under the GNU General Public License version 3 or later ([LICENSE](../LICENSE)). It costs nothing to use, and no feature is held back for payment.

## Where things stand

- **There is no funding set up.** No sponsorship page, donation link, paid tier or paid support exists for this project at the time of writing. If you see one claiming to be the Media bank's, it is not.
- **There is no paid support.** Help is given on a best-effort basis ([SUPPORT.md](SUPPORT.md)). Paying someone does not move a request up the queue, because there is no queue to pay for.
- The project is looked after by one person in their own time ([GOVERNANCE.md](GOVERNANCE.md)).

## How you can help without money

These matter more to a project at this stage than a donation would:

| What | Why it helps | How |
|---|---|---|
| **Try it on a test site and report what you find** | Beta software needs real use on real sites | [SUPPORT.md](SUPPORT.md) |
| **Answer another person's question** | Saves the maintainer's time | Issues on GitHub |
| **Improve a guide** | Most problems are a sentence that was unclear | [STYLE-GUIDE.md](STYLE-GUIDE.md), then a pull request |
| **Test on a Moodle version or setup not yet covered** | The CI covers 5.0 to 5.3 on two databases and two PHP versions, not every host | an issue with what you tried and what happened |
| **Translate the language strings** | Moodle sites run in many languages | [CONTRIBUTING.md](../CONTRIBUTING.md) |
| **Report a security problem privately** | Fixes people before it harms a site | [SECURITY.md](../SECURITY.md) |
| **Tell other Moodle administrators** | More testers find more problems | |

Anyone who helps can be named in [CONTRIBUTORS.md](CONTRIBUTORS.md).

## If funding is ever added

The maintainer may set up a way to sponsor the project later, for example through GitHub Sponsors. If that happens:

1. It will be announced in the changelog and shown in this file and in the GitHub repository's **Sponsor** button, which comes from `.github/FUNDING.yml`. Treat anything else as not from the project.
2. **Money buys no control.** A sponsor gets thanks, not a vote. Decisions are made as described in [GOVERNANCE.md](GOVERNANCE.md), and the standing rules (for example that SVG stays off by default, and that nothing personal is published) do not change for a sponsor.
3. **No feature is locked.** The plugins stay fully functional and under the same licence.
4. **No private data is collected** by the plugins to find or bill anyone. Sponsorship is handled by the platform, not by the plugins.
5. A sponsor may ask to be named in [ACKNOWLEDGEMENTS.md](ACKNOWLEDGEMENTS.md) or [CONTRIBUTORS.md](CONTRIBUTORS.md), or not.
6. What the money is spent on is stated in this file.

## Paid work around the project

You are free to pay anyone, including the maintainer, to install, support, train staff on or customise the Media bank on your own site. That is a private agreement between you and them. It is not funding of the project, and it does not change what the project does. The licence lets you, or someone you hire, change your own copy and share the result under the same licence.

## Funding and the Moodle Plugins directory

The Moodle Plugins directory ([PLUGIN-DIRECTORY.md](PLUGIN-DIRECTORY.md)) is for free plugins. This project is not a Moodle Marketplace product, and nothing here applies to selling it.
