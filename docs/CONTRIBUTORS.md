# Media bank: Contributors

Thank you to everyone who has helped build the Media bank.

## Maintainer

- **Bill White** ([SenseiMoodle](https://github.com/billsensei)): owner and maintainer. Set the direction, chose the policies (for example that SVG is off by default, and that erasing a person keeps courses' files as copies), and approves every release.

## Built with

- **Claude** (an AI assistant made by Anthropic) wrote much of the code, tests and documentation, working with Bill White in Claude Code. Commits that Claude helped write say so in a `Co-Authored-By` line. Everything was reviewed and run by the maintainer before release.
- **Automated security reviews** looked at the code before each release and found real problems that were fixed first. They are recorded in `contenttype_mediabank/CHANGES.md`.

## Standing on the shoulders of

- **Moodle** and the Moodle community, for the Content bank, the file picker and the plugin APIs this project builds on. Moodle is licensed under the GNU GPL v3, like these plugins.
- **moodle-plugin-ci** and Moodle's coding-standard tools, which the GitHub Actions workflow uses on every push.

## Your name here

Contributions of any size count: a bug report, a better sentence in a guide, a test, a translation, a fix. See [CONTRIBUTING.md](../CONTRIBUTING.md) for how to start.

When a contribution is merged, add yourself to this file in the same pull request (or ask in it, and the maintainer will add you), in the form:

    - **Your Name** ([github-handle](https://github.com/github-handle)): what you did.

Report a security problem privately, as [SECURITY.md](../SECURITY.md) describes. You will be thanked here too, unless you prefer not to be named.
